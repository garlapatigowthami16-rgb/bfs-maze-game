# BFS Maze Game – Discover the Shortest Path

## About the Project
This project demonstrates how the Breadth-First Search (BFS) algorithm finds the shortest path from a starting point to a destination in a maze.

## Objective
To help users understand how BFS explores different paths and finds the shortest route through a maze.

## Technologies Used
- HTML
- CSS
- JavaScript

## Algorithm Used
- Breadth-First Search (BFS)

## Features
- Generate random mazes
- Manual mode
- Automatic mode
- Step-by-step search explanation
- Visualize the shortest path

## How to Run
1. Download or clone this repository.
2. Open the `maze.html` file in a web browser.
3. Start exploring the maze!

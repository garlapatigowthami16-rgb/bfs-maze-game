💡 BFS in a nutshell

1. Add START to queue
2. Remove front cell
3. Check its neighbours
4. Mark new cells + record parent
5. Repeat until GOAL is found
6. Follow parents backwards
Because every move costs one step, BFS finds a shortest path in an unweighted maze.
Tip: use Manual mode to inspect each decision. Use Auto Mode to watch the search unfold. The green trail appears after BFS reaches the goal.
